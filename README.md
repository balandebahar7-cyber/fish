# Spring Fishing Shop (نمونه‌کار پورتفولیو / Portfolio demo)
## اجرا / Run
پوشه را باز کنید و `index.html` را در مرورگر اجرا کنید (یا `python3 -m http.server`).
## انتشار در GitHub Pages
1. یک ریپازیتوری جدید بسازید (مثلاً `spring-fishing-shop`).
2. همه فایل‌ها را در ریشه آپلود کنید (index.html کنار css و js).
3. Settings → Pages → Branch: main / root → Save.
4. آدرس: `https://USERNAME.github.io/spring-fishing-shop/`
سایت کاملاً مستقل است و به هیچ پروژه دیگری وابسته نیست. پرداخت و سفارش فقط شبیه‌سازی است.
